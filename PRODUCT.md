# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Vite + TypeScript + native Canvas 2D and DOM UI, selected for a stable, dependency-light browser MVP.

## Users

Professional and advanced rhythm-platform players who value precise timing, fast restarts, difficult patterns, and readable high-contrast feedback.

## Product Purpose

An original high-difficulty rhythm platform game with automatic forward motion, multiple movement modes, short playable prototype levels, and a real level editor that makes the core loop testable in a browser.

## Positioning

The product combines a precision-first arcade loop with an inspectable JSON level format and an in-browser editor, so players can both master authored challenges and create/test their own patterns without a backend.

## Operating Context

Desktop keyboard/mouse and mobile touch are first-class input paths. Player progress and custom levels are stored locally in the browser. The first release uses short prototype levels rather than full-length campaigns.

## Capabilities and Constraints

The brief requires Cube, Ship, Ball, UFO, Wave, and Swing modes; gravity, mini, dual, speed, and portal systems; Normal, Practice, and Noclip modes; 11 official prototype slots; and a functional editor with JSON-friendly objects, undo/redo, save/load, test play, and localStorage persistence. All game names, UI copy, visual geometry, sound feedback, and code are original.

## Brand Commitments

Temporary original title: SIGNAL//RIFT. Visual direction: dark, neon, cyber geometry with one acid-green accent and restrained cyan telemetry.

## Evidence on Hand

No pre-existing assets or content. Gameplay patterns and level names are authored for this MVP and are not copied from any named reference game or level.

## Product Principles

- Precision before spectacle.
- Fast recovery after failure.
- Every system should be inspectable and extensible.
- Difficulty is communicated clearly, never hidden behind decoration.
- Local-first authoring keeps the MVP easy to run and deploy.
